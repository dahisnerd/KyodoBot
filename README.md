# 🎮 Kyodo Games Bot — بوت ألعاب كيودو المتكامل

بوت ألعاب تفاعلي متكامل ومطور لمنصة التواصل الاجتماعي **Kyodo** باستخدام لغة بايثون ومكتبة `kyodo` الرسمية.

يتميز البوت بنظام ألعاب تفاعلي يدعم اللعب الجماعي والثنائي والفردي بالكامل باللغة العربية، بالإضافة إلى نظام ترحيب وتوديع تلقائي يعتمد على توليد صور مخصصة لكل عضو يدخل أو يغادر المجموعة.

---

## ✨ المميزات الرئيسية

- **ألعاب ذكية بدون أوامر معقدة:** بعد كتابة أمر بدء اللعبة، يمكنك إرسال ردود طبيعية مباشرة في الدردشة (مثل: "سحب"، "وقوف"، "أعلى"، "أقل"، أو الأرقام `1`-`9`) لتسهيل اللعب.
- **نظام الترحيب والتوديع التلقائي (Image-based Welcome/Goodbye):** يقوم البوت تلقائيًا بتحميل صورة العضو وتصميم بطاقة ترحيبية أو توديعية مخصصة له بجودة عالية وتأثيرات ألوان متناسقة وخلفيات متدرجة (Gradient) باستخدام مكتبة **Pillow**.
- **دعم الألعاب المتعددة:** يحتوي البوت على أكثر من 25 لعبة متنوعة تشمل ألعاب الطاولة، الكلمات، الأرقام، الورق، والنرد.
- **إدارة الجلسات:** نظام تعقب لحالة كل لعبة ونقاط اللاعبين داخل كل مجموعة بشكل منفصل لمنع تداخل الألعاب.

---

## 🎮 قائمة الألعاب المتوفرة

### ❌⭕ ألعاب الطاولة
- `/xo` — لعبة XO الكلاسيكية (لاعبين).
- `/xo_bot` — لعبة XO ضد البوت (ذكاء اصطناعي ذكي).
- `/c4` أو `/كونيكت` — لعبة Connect 4 الشهيرة (لاعبين).

### 📝 ألعاب الكلمات
- `/مشنقة` — لعبة المشنقة الكلاسيكية لتخمين الحروف.
- `/مبعثرة` — لعبة ترتيب الحروف المبعثرة لمعرفة الكلمة الصحيحة.
- `/سلسلة` — لعبة سلسلة الكلمات (الكلمة التالية تبدأ بآخر حرف من الكلمة السابقة).
- `/سباق_كتابة` — تحدي سرعة الكتابة بين لاعبين.
- `/تخمين` — تخمين الكلمة بناءً على وصف وتلميح يقدمه البوت.

### 🔢 ألعاب الأرقام
- `/خمن` — تخمين رقم عشوائي بين 1 و 100 مع تلميحات (أكبر / أصغر).
- `/اعلى` — تحدي "أعلى أم أقل" بين لاعبين (تخمين هل الرقم التالي أكبر أم أصغر).
- `/رياضيات` — دوري الرياضيات وسرعة الحساب بين لاعبين.
- `/عد` — تحدي العد الجماعي المتعاقب بالتناوب.
- `/متسلسلة` — إكمال متسلسلة الأرقام الحسابية.
- `/حساب` — تحدي حسابي سريع لأسرع إجابة.

### 🃏 ألعاب الورق
- `/بلاك` — لعبة البلاك جاك الكلاسيكية (فردي ضد الديلر).
- `/حرب` — حرب الورق وتحدي الحظ بين لاعبين.
- `/لون` — تخمين لون الكرت القادم (أحمر أم أسود).
- `/ورقة` — لعبة الورقة الأعلى بين لاعبين.

### 🎲 ألعاب النرد
- `/نرد` — رمي نردين لمعرفة المجموع.
- `/نرد_دوري` — تحدي دوري رمي النرد بين لاعبين.
- `/سباق` — سباق النرد الجماعي للوصول إلى 50 نقطة أولاً.
- `/محظوظ` — لعبة المحظوظ 7 (الفوز إذا كان مجموع النرد 7).
- `/مجموع` — تخمين مجموع النردات المخفية.

## 🚀 طريقة التثبيت والتشغيل

### 1. المتطلبات الأساسية
تأكد من تثبيت Python 3.10 أو أحدث على جهازك.

### 2. تثبيت المكتبات المطلوبة
قم بتشغيل الأمر التالي في سطر الأوامر لتثبيت التبعيات اللازمة:
```bash
pip install kyodo Pillow requests websocket-client httpx aiofiles aiohttp aiohttp_socks orjson pyjwt
```

### 3. إعداد الإعدادات
قم بفتح ملف `config.py` وتعديل البيانات التالية:
```python
EMAIL = "your_email@gmail.com"  # بريدك الإلكتروني في كيودو
PASSWORD = "your_password"       # كلمة المرور
```
*(أو يمكنك وضع الـ `TOKEN` مباشرة إذا كان لديك).*

### 4. التشغيل
لتشغيل البوت، فقط قم بتنفيذ الملف الرئيسي:
```bash
python bot.py
```
